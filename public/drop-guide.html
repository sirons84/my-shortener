누리집 펴내기 베타

HTML 파일 한 장을 끌어다 놓으면 외솔.한국/우리반 같은 한글 주소로 바로 펴냅니다. 서버도, 설치도, 코딩 지식도 필요 없습니다. 아래 다섯 단계만 따라 하면 됩니다.

1. 접속·로그인 2. 누리집 펴내기 찾기 3. 파일 올리기 4. 주소·기간 정하기 5. 펴내기 6. 바꾸기·내리기 자주 묻는 질문

시작하기 전에 준비할 것

  • HTML 파일 1개 (.html 또는 .htm, 1MB 이하). 챗GPT·클로드·제미나이 등에 "학급 안내장 HTML 한 장으로 만들어 줘"라고 하면 바로 받을 수 있습니다.
  • 외솔.한국 계정. 펴내기는 로그인한 선생님만 할 수 있습니다.
  • 컴퓨터. 휴대폰에서는 파일 올리기가 잘 안 될 수 있습니다.
1

외솔.한국에 접속해 로그인합니다

주소창에 외솔.한국을 입력합니다. 오른쪽 위 선생님 로그인을 누르고 이메일과 비밀번호를 입력합니다. 계정이 없으면 로그인 화면 아래 회원가입으로 만들 수 있습니다.

외솔.한국 첫 화면. 오른쪽 위 「선생님 로그인」

로그인 화면

로그인하지 않으면 펴낼 주소 옆에 "🔒 로그인하면 펴낼 수 있어요"가 표시되고 펴내기 버튼이 동작하지 않습니다.
2

첫 화면을 아래로 내려 「누리집 펴내기」를 찾습니다

단축 주소 만들기 카드 바로 아래에 누리집 펴내기 베타 카드가 있습니다. 파일을 놓는 점선 상자, 펴낼 주소, 유지 기간, 펴내기 버튼이 한 카드 안에 모여 있습니다.

누리집 펴내기 카드. 이미 펴낸 누리집이 있으면 맨 위에 「펴낸 누리집」으로 표시됩니다

3

HTML 파일을 끌어다 놓습니다

탐색기(파인더)에서 HTML 파일을 잡아 점선 상자 위에 놓습니다. 상자를 클릭해서 파일을 고를 수도 있습니다. 파일을 올리면 상자 안에 파일 이름이 표시되고, 펴낼 주소 칸에 파일 이름이 자동으로 들어갑니다.

파일이 없고 코드만 있다면 상자 아래 「파일 대신 코드를 붙여넣기」를 누르고, 열리는 칸에 HTML 코드를 통째로 붙여넣습니다.

위: 파일을 놓는 곳 · 아래: 「파일 대신 코드를 붙여넣기」를 눌렀을 때

올릴 수 있는 파일: .html, .htm 한 장, 최대 1MB. 그림·CSS·자바스크립트가 따로 파일로 나뉘어 있으면 안 됩니다. AI에게 요청할 때 "파일 하나에 전부 담아서(이미지는 링크나 base64로)"라고 말하면 됩니다.
4

펴낼 주소와 유지 기간을 정합니다

펴낼 주소에는 외솔.한국/ 뒤에 붙을 이름을 씁니다. 한글, 영문, 숫자, 붙임표(-), 밑줄(_)을 50자까지 쓸 수 있습니다. 공백과 점(.), 빗금(/)은 쓸 수 없습니다. 예를 들어 우리반-가정통신문이라고 쓰면 주소는 외솔.한국/우리반-가정통신문이 됩니다.

유지 기간은 1개월 · 6개월 · 1년 · 무제한 중에서 고릅니다. 기간이 지나면 페이지가 자동으로 내려갑니다. 기본값은 1년입니다.

펴낼 주소를 입력하고 유지 기간을 고른 모습

이미 쓰는 주소는 쓸 수 없습니다. 단축 주소와 펴낸 누리집이 같은 이름 공간을 쓰기 때문에 "이미 사용 중인 주소입니다"가 뜨면 다른 이름으로 바꿔 주세요.
5

「펴내기」를 누르면 끝입니다

주황색 펴내기 버튼을 누릅니다. 잠시 뒤 "펴내기 완료" 카드가 나타나고, 완성된 주소가 보입니다. 열어보기로 바로 확인하고, 주소 복사로 복사해서 학급 알림장이나 단체 대화방에 붙여넣으면 됩니다.

6

내용을 바꾸거나 페이지를 내리려면

같은 주소에 새 파일을 올리고 싶을 때: 첫 화면 누리집 펴내기 카드 위쪽 「펴낸 누리집」 목록에서 「이 페이지 교체」를 누른 뒤, 새 파일을 올리고 교체하기를 누릅니다. 주소는 그대로 두고 내용만 바뀝니다. 반영에는 1분 정도 걸릴 수 있습니다.

첫 화면의 「펴낸 누리집」 목록과 「이 페이지 교체」 버튼

페이지를 내리거나 자세히 관리할 때: 오른쪽 위 내 주소 관리(대시보드)로 들어가 누리집 펴내기 탭을 엽니다. 페이지마다 조회 수, 용량, 만료일이 보이고 열어보기 · 주소 복사 · 다른 파일로 교체 · 내리기 버튼이 있습니다.

대시보드 → 누리집 펴내기 탭

내리기를 누르면 페이지가 즉시 사라지고 되돌릴 수 없습니다. 다시 쓰려면 파일을 새로 올려야 합니다.

자주 묻는 질문

몇 개까지 펴낼 수 있습니까?

계정당 5개입니다. 한도가 차면 기존 페이지를 교체하거나 대시보드에서 내린 뒤 새로 올릴 수 있습니다. 카드 아래에 "1 / 5개 사용 중"처럼 현재 상태가 표시됩니다.

올린 페이지는 누가 볼 수 있습니까?

주소를 아는 사람은 누구나 볼 수 있습니다. 로그인은 필요 없습니다. 다만 검색 엔진에는 나오지 않으니 주소를 받은 사람만 찾아올 수 있습니다. 학생 개인정보가 담긴 내용은 올리지 마십시오.

그림이 안 보입니다.

HTML 안에서 그림을 img/사진.png처럼 같은 폴더의 파일로 불러오면 누리집 펴내기에서는 보이지 않습니다. 파일은 한 장만 올라가기 때문입니다. 그림은 인터넷 주소(https://…)로 넣거나, AI에게 "이미지를 base64로 HTML 안에 넣어 줘"라고 요청하십시오. 전체 용량이 1MB를 넘지 않게 주의합니다.

"HTML 파일이 아닌 것 같습니다"가 뜹니다.

붙여넣은 내용에 HTML 태그가 없을 때 나오는 안내입니다. <!doctype html>로 시작하는 코드 전체를 붙여넣었는지, 확장자가 .html인지 확인하십시오. 한글(hwp)·워드·PDF 파일은 올릴 수 없습니다.

교체했는데 예전 내용이 보입니다.

서버가 페이지를 잠깐 저장해 두기 때문에 최대 1분 정도 지난 뒤 새로고침하면 바뀐 내용이 보입니다. 그래도 그대로면 브라우저 새로고침(Ctrl+F5)을 해 보십시오.

유지 기간이 끝나면 어떻게 됩니까?

주소로 들어가면 "게시 기간이 끝난 페이지입니다"가 표시됩니다. 계속 쓰려면 기간이 끝나기 전에 대시보드에서 「다른 파일로 교체」로 같은 파일을 다시 올리거나, 처음부터 「무제한」으로 펴내기하십시오.

휴대폰에서도 펴낼 수 있습니까?

보는 것은 휴대폰에서도 문제없습니다. 다만 파일을 올리는 작업은 기기에 따라 잘 되지 않을 수 있어 컴퓨터에서 하기를 권합니다.
